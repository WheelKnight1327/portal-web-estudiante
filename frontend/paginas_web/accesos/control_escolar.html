Vínculo de acceso

A partir del 18 de marzo del 2025, se implementó el nuevo sistema de control escolar. El sistema anterior, ase1.ceti.mx, está deshabilitado.
Para acceder al nuevo sistema, entre a este vínculo: https://escolomos.ceti.mx/

Dudas y soporte

Para restablecer la contraseña, mande correo a atencion.alumnos.col@ceti.mx o diríjase a la ventanilla de apoyo académico (enfrente al estacionamiento).
