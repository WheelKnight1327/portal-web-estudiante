¿Que es el portal del estudiante?

Es un portal web informativo dirigido a los estudiantes del Centro de Enseñanza Técnica Industrial, para cualquier modalidad y carrera, que recopila todos los recursos de la escuela relacionados con trámites administrativos, recursos digitales, instrucciones de uso y los anuncios más relevantes con el propósito de facilitar el seguimiento de todos las actividades necesarias para completar la carrera sin retrasos o complicaciones.
Te invitamos a que revises todas las columnas, puede que descubras recursos o si deseas conocer las instrucciones o requerimientos para un trámite que tengas pendiente, uses la barra de busqueda para encontrar el trámite.
